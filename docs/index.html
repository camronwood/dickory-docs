Dickory Docs is a native desktop app for local Markdown and Mermaid — add folder workspaces, browse the tree, and preview rendered docs without a separate server or cloud sync.

What you get

A focused doc viewer for repos and notes — not an IDE, not a chat hub. Everything runs on your machine.

📁

Multi-folder workspaces

Add directories as workspaces; roots and metadata persist under your OS config dir. Git branch and remote show when the folder is a repo.

📝

Markdown & Mermaid

Rendered preview with sanitised HTML, title extraction, and inline Mermaid diagrams you can expand to a modal for complex charts.

Deep dive →

🌲

File explorer

Resizable sidebar, markdown-only filter, context-menu create/rename/delete, and plain-text view for non-Markdown files.

Deep dive →

🖥️

Native desktop shell

Tauri + React with a Slack-inspired dark UI. File reads and workspace state stay in-process — no companion hub or network service.

🔒

Path-safe I/O

Rust backend normalises paths, rejects .. escapes, and serves file trees relative to each workspace root.

⚡

Preview deep links

Open a specific file via query params (?preview=true&workspace=&path=) for bookmarks or tooling integration.

How you work in it

Open Dickory Docs, pin your doc folders, and read — the tree and preview stay in sync.

Browse & filter

  • Switch workspaces from tabs in the explorer.
  • Toggle Markdown only to hide noise in large repos.
  • Expand folders lazily; selection drives the main pane.

Read & sketch

  • Markdown renders with GFM-style parsing via marked.
  • Mermaid blocks render as SVG; click to expand busy diagrams.
  • Non-.md files open as monospace plain text.
