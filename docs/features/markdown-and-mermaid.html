Markdown & Mermaid preview

Select a .md file and read rendered HTML in the main pane — with fenced Mermaid blocks turned into SVG diagrams.

Rendering pipeline

The frontend reads file bytes through Tauri commands, parses Markdown with marked, sanitises HTML with DOMPurify, and injects the result into the preview pane. The window title updates to {heading} · Dickory Docs when a title can be extracted from the document.

Mermaid diagrams

Fenced ```mermaid blocks are split out and rendered separately via the Mermaid library. Each diagram shows inline in the preview; click to open a modal for large or detailed charts. Failed renders surface an error state with retry.

Content hashing

The preview tracks a content hash so it can avoid redundant re-renders when the underlying file has not changed.

Preview deep links

For automation or bookmarks, load the app with query parameters:

  • preview=true
  • workspace={workspaceId}
  • path={relativePath}

On mount, the app selects that Markdown file automatically when all three are present.
